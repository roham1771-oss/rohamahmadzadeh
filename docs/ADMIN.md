# Administrator Guide

## Accessing Admin Panel

Navigate to `/fa/admin` and login with admin credentials.

## Dashboard

The dashboard shows:
- Total clients
- Active cases
- Pending tasks
- Monthly revenue

## Client Management

- View all clients
- Search and filter
- View client details
- Manage client documents

## Case Management

- Create new cases
- Track case status (Open, Active, Pending, Closed, Won, Lost, Settled)
- Set priority levels
- Add timeline events
- Attach documents
- Set deadlines

## Article Management

- Create articles in Persian and English
- Draft/Published/Archived status
- Categories and tags
- View count tracking

## Appointment Management

- Schedule office, phone, or video consultations
- Track appointment status
- Client association

## Document Management

- Upload documents (PDF, DOCX, Images)
- Organize by category
- Mark as confidential
- Associate with cases/clients

## Invoice Management

- Create invoices
- Track payment status
- Generate reports

## Task Management

- Create tasks
- Assign priority
- Set due dates
- Link to cases/clients

## Calendar

- View all appointments
- Track deadlines
- Court hearing dates

## Settings

- System configuration
- User management
- Email templates
